## Featured Projects

### [Unity-MCP Pro](https://github.com/NishantJLU/Unity-MCP)
> Agentic bridge between LLMs and the Unity game engine via MCP Protocol

Enables AI assistants to directly control Unity scenes, GameObjects, components, and physics workflows in real time. Implements a C# bridge dispatcher in the Unity Editor, a Node.js MCP server, and an AI Vision module for visual scene reasoning through screenshot capture.

**Tech:** C# · Node.js · TypeScript · MCP Protocol · WebSockets

### [AI-LMS Platform](https://github.com/NishantJLU/AI-LMS)
> AI-powered Learning Management System

Full-stack LMS with OpenAI-driven quiz generation from course content, role-based access for students and teachers, progress tracking dashboards, and secure authentication via Auth.js. Containerized with Docker and deployed via CI/CD on Vercel.
