## About me

I'm a BTech student focused on building AI-powered applications, scalable web platforms, and developer tooling. My work consistently aims at connecting systems that weren't designed to talk to each other — LLMs with game engines, semantic caches with relational graphs, and visual dashboards with agentic workflows.

Check out my interactive, immersive portfolio at **[builtbynishant.dev](https://builtbynishant.dev)** (featuring a CRT terminal interface and real-time system telemetry).
