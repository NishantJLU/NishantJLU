## About me

I'm a BTech student focused on building AI-powered applications, scalable web platforms, and developer tooling. My work consistently aims at one thing: connecting systems that weren't designed to talk to each other — LLMs with game engines, AI with education, creativity with engineering.

Currently maintaining **Unity-MCP Pro**, an open-source agentic bridge between LLMs and the Unity Editor, and developing a full-stack **AI-powered LMS** with Next.js and OpenAI. Open to internships, collaborations, and open-source contributions.
